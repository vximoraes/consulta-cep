# 🌎 Consulta CEP

Este projeto permite consultar endereços a partir de CEPs brasileiros, consumindo APIs públicas e apresentando uma interface moderna, responsiva e agradável.

## ✨ Features
- Consulta endereços a partir do CEP informado.
- Interface responsiva e amigável para dispositivos móveis.
- Consumo de APIs públicas para busca de endereços.
- Visual moderno e fácil de usar.
